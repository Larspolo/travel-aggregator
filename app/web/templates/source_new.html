{% call ui.card("Steps") %}
  1. Open the website and do a search for a trip.
  2. Open the developer tools (F12) and select the tab "Network".
  3. Reload the page and wait until the results show.
  4. Right-click a request and select "Save all as HAR". Use the option "sanitized" if your browser has it.
  5. Open the HAR file in a text editor and remove cookies, tokens, names, e-mail addresses and booking codes. The issue is public.
  6. Open a new GitHub issue, drag the HAR file into the text, and submit the issue. The agent then writes the userscript and the parser.
